# Monash WAM Calculator\n\nA modern, responsive web application for calculating Weighted Average Mark (WAM) for Monash University students. Built with React, TypeScript, and Tailwind CSS.\n\n**Live Demo**: [monashwamcalculator.com](https://monashwamcalculator.com)\n\n## Features\n\n- **Monash WAM Calculator** - Calculate your Weighted Average Mark with real-time results\n- **WAM to GPA Converter** - Convert WAM to both 4.0 and 7.0 GPA scales\n- **GPA to WAM Converter** - Reverse convert GPA back to approximate WAM\n- **Final Grade Calculator** - Calculate required exam marks for target grades\n- **Dark/Light Mode** - Toggle between themes with localStorage persistence\n- **Responsive Design** - Optimized for mobile, tablet, and desktop\n- **Copy Results** - Share your WAM results with one click\n- **Real-time Calculation** - Instant updates as you enter grades\n- **Grade Reference** - Built-in grade scale reference (HD, D, C, P, N)\n- **SEO Optimized** - Includes meta tags, Open Graph, JSON-LD schema\n- **Accessibility** - Semantic HTML and ARIA labels\n\n## Quick Start\n\n### Prerequisites\n\n- Node.js 16.x or higher\n- npm or yarn\n\n### Installation\n\n```bash\n# Clone the repository\ngit clone https://github.com/asbusiness276-cyber/monash-wam-calculator.git\ncd monash-wam-calculator\n\n# Install dependencies\nnpm install\n\n# Start development server\nnpm run dev\n\n# Open http://localhost:5173 in your browser\n```\n\n### Build for Production\n\n```bash\nnpm run build\nnpm run preview\n```\n\n## Project Structure\n\n```\nsrc/\n├── components/\n│   ├── Navbar.tsx           # Navigation bar with dark mode toggle\n│   ├── Footer.tsx           # Footer with links and info\n│ weighted marks are summed, then divided by total credit points.\n\n### Grade Scale\n\n| WAM Range | Grade | Label            |\n|-----------|-------|------------------|\n| 80–100    | HD    | High Distinction |\n| 70–79     | D     | Distinction      |\n| 60–69     | C     | Credit           |\n| 50–59     | P     | Pass             |\n| 0–49      | N     | Fail             |\n\n## Tech Stack\n\n- **Frontend**: React 18 + TypeScript\n- **Styling**: Tailwind CSS with dark mode support\n- **Build Tool**: Vite\n- **Icons**: Lucide React\n- **State Management**: React Hooks\n- **Routing**: Client-side navigation\n\n## Features Breakdown\n\n### Monash WAM Calculator\n- Add/remove unlimited subjects dynamically\n- Enter unit name, final mark (0-100), and credit points\n- Real-time WAM calculation as you type\n- Automatic grade classification (HD, D, C, P, N)\n- Display total credits, average mark, and current WAM\n- Copy results to clipboard\n- Reset calculator button\n- Grade reference guide inline\n\n### WAM to GPA Converter\n- Convert WAM to 4.0 GPA scale\n- Convert WAM to 7.0 GPA scale\n- Full conversion reference table\n- Grade classification display\n\n### GPA to WAM Converter\n- Switch between 4.0 and 7.0 scales\n- Reverse convert to approximate WAM range\n- Conversion reference table\n- Grade classification display\n\n### Final Grade Calculator\n- Enter current mark and coursework weight\n- Set target overall mark and final exam weight\n- Calculate required final exam mark\n- Display achievability status\n- Show common target grades reference\n\n## Deployment\n\nThis project is optimized for deployment on any static hosting:\n\n### Vercel (Recommended)\n\n```bash\nnpm install -g vercel\nvercel\n```\n\n###
